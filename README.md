# 🇮🇳 India Time & Calendar

A simple and responsive web project that displays the current Indian Standard Time (IST) and an interactive Indian festival calendar.

## Project Preview

![India Time & Calendar](screenshot.png)

##  Features

-  Real-time Indian Standard Time
- 🇮🇳 Delhi, India • IST
-  Interactive monthly calendar
-  Direct year selection
-  Indian festivals and important days
-  Today button
-  Previous / Next month navigation
-  Festival details
-  Responsive design
-  Works directly in the browser
-  Designed by Chetan Chauhan

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts – Ubuntu
